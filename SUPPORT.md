# Support

Use the appropriate channel:

- product defect or enhancement — GitHub Issue in the affected repository;
- architecture decision — Architecture issue using the organization template;
- security vulnerability — follow `SECURITY.md`, never create a public issue;
- production incident — use the approved internal incident-management process;
- Business Central, Autodesk ACC, IBM Cloud, watsonx, or Vault access — contact the relevant platform owner.

Include the affected component, environment, expected behavior, actual behavior, reproducible steps, and non-sensitive logs.
