# HellCold GitHub Organization

Public organization defaults for the `HellCold-Sp-z-o-o` GitHub organization.

This repository provides organization-wide contribution guidance, issue and pull request templates, security reporting instructions, and reusable baseline workflows. Repository-specific files take precedence where GitHub supports overrides.

## Contents

- `.github/ISSUE_TEMPLATE/` — default issue forms.
- `.github/PULL_REQUEST_TEMPLATE.md` — default pull request template.
- `.github/workflows/` — validation and reusable workflows.
- `workflow-templates/` — starter workflow shown when creating workflows in organization repositories.

## Scope and security

This repository is intentionally public so GitHub can use its supported community health files as organization defaults. It must contain no secrets, customer data, production identifiers, private architecture, credentials, or operational exports.

The full HC-STD-GIT-001 standard and internal organization configuration are maintained in a private governance repository. This public repository intentionally excludes repository catalogs, criticality, production scope, internal ownership, environment identifiers, and administrative configuration.

## Ownership

- Business owner: HellCold Management
- Technical owner: HellCold Platform & Architecture
- Classification: Public
- Criticality: C2 — Business
- Lifecycle: Active

## Internal standard

All organization repositories are governed by HC-STD-GIT-001. Organization members should consult the approved private governance source before changing repository policy or administration.
